# Thegame: упрощённый сетевой открытый мир

Это разрешённый пользователем on-foot вариант переноса. Не прежняя полная GTA-подобная игра и не офлайн-демо под видом сетевой комнаты.

## Запуск

Из ветки product/unified-engine:

```sh
bun install --frozen-lockfile
npm install --prefix tools/docs --ignore-scripts
bun run docs:build
bun run thegame
```

Открыть http://127.0.0.1:4173/games/thegame/ в двух окнах браузера с WebGPU. Один процесс Bun обслуживает статический клиент и WebSocket authority. Для других устройств нужен HTTPS reverse proxy к этому процессу: WebGPU требует secure context, исключение localhost не распространяется на обычный HTTP-адрес локальной сети. Публичный сервер этим коммитом не развёрнут. HOST (по умолчанию 0.0.0.0), PORT (4173), THEGAME_SITE и THEGAME_ORIGINS задаются через окружение. Проксировать WebSocket Upgrade и сохранять Host; TLS завершать на прокси. Не заменять недоступную сеть локальным authority.

WASD/стрелки — движение, Shift — бег, пробел — прыжок. Перетаскивание сцены мышью — камера, M — карта, Ё — диагностика. На touch-экране есть кнопки перемещения/прыжка. Кнопка приглашения копирует адрес текущего сервера. Исследовать пять отмеченных мест; открытия проверяет сервер. В мире также восемь простых серверных пешеходов.

## Что перенесено и что сокращено

Из Pom4H/thegame перенесены on-foot motor (character.ts blob 1d19ad8662ab), deterministic hash (shared/math.ts 87384a931250), климатические переходы и геометрия магистралей (biomes.ts c6a4516b665b), исходная позиция -345/-66, метровые координаты и правила осей. Новый облегчённый генератор сохраняет город/пригороды/природные биомы; новый WORLD_REVISION thegame-lite/1 явно отделяет его от старых сохранений. У зданий упрощены фасады, нет интерьеров. Нет транспорта, боёв, полиции, экономики, голосового чата, долговременных сохранений; вода в этой версии поддерживает персонажа на поверхности, полноценного плавания нет.

## Один движок

Обычный TypeScript-проект examples/thegame/project.ts подключает модуль thegame. Сервер и предсказание клиента исполняют одну функцию stepCharacter и одну геометрию столкновений OpenWorld. Отображение использует существующие Scene/WebGPURenderer, humanoid/sampleWalker/bindHumanoid, Replica/PlaybackClock, FixedClock, SourceDocument/AST bindings/compiler, CpuProfiler/RuntimeTimeline. Новый renderer и отдельная система физики не создавались. Scene клиента не шагает, физических тел в нём нет; предсказывается только собственный character motor.

Код ↔ мир использует общий workbench. viewRadius/exposure применяются в живой сетевой сессии без пересоздания игрока. Seed/скорости/гравитация/прыжок — свойства общего мира: менять исходник и перезапускать сервер. Клиент отклоняет несовместимую физику, а не расходится с authority. Ошибочный исходник не заменяет действующий мир.

## Бюджеты и сеть

Authority 60 Hz, публикация 20 Hz, максимум 32 соединения. ACK означает исполненную команду, не получение. Сервер принимает только ограниченные направления/поворот/кнопки, никогда клиентскую позицию или dt. Не более 32 команд в пакете / 120 в очереди. Неподвижный ввод не останавливает гравитацию. Отдельный self+ACK не вытесняется AOI; остальные игроки видимы в радиусе 512 м. Пакеты имеют schema/epoch/tick/sequence. Локальное предсказание хранит не более 120 команд, сверяется с authority и переигрывает остаток. Остальные персонажи отображаются через единственный PlaybackClock с буфером 120 мс, без второй NPC-симуляции.

Входящие сетевые сообщения разбираются в worker; главный поток получает один последний снимок по запросу, не накапливает очередь задач. Исходящая отправка ограничена bufferedAmount. На сервере Bun send=-1 уже поставил пакет в очередь: его нельзя повторять; до drain сохраняется один новый state. Зависшее соединение закрывается, а не нагружает память бесконечно. Неактивное окно отключается и восстанавливает серверную позицию при возврате. Resume token живёт 30 секунд в памяти сервера, не передаётся другим игрокам; перезапуск сервера начинает новую сессию.

Чанки 128 м, terrain grid 8 м; высота коллизий вычисляется по тем же треугольникам, а не другой интерполяции. Геометрия создаётся в worker: один запрос/один готовый результат. Не более одного admission на кадр. GPU использует chunk-local меши; render-origin меняется по 128 м, не меняя абсолютные сетевые координаты и меши оставшихся чанков. Радиус 1..4 (9..81 чанков), CPU collision LRU 64 на клиенте / 128 на сервере / 16 в geometry worker. Размер самого мира не определяет постоянное потребление памяти.

## Проверка

node --test test/thegame.test.mjs проверяет seams/triangle parity, биомы/ограничения LRU, движение/прыжок/коллизии, запрет телепортов, очередь/ACK/replay, stale epochs, AOI, chunk admission, composition и backpressure/resume.

THEGAME_PROFILE=1 включает измерение authority и ограниченную причинную трассу. /thegame/health содержит только агрегаты, без resume tokens. Клиентская Ё показывает реальные очереди, RTT, коррекции, чанки и renderer CPU/GPU. Метрики не обещают нулевую задержку для любого Интернета.

node tools/thegame/qa.mjs запускает настоящий Bun и два независимых Chrome/WebGPU. Loopback-only relay вводит 50±30 мс в каждую сторону с сохранением порядка и отбрасывает 5% заменяемых снимков на уровне приложения (это не симуляция TCP packet loss). Проверяются native keyboard/jump, 240+ м реального перемещения через границы чанков, видимость игрока во втором клиенте, изменение DSL, reconnect и мобильная вёрстка. Скриншоты — из реального приложения. Приёмочные бюджеты: frame p95 <50 мс, максимум <250 мс в измеренном проходе после загрузки, reconciliation p95 <0.3 м. Они не равны обещанию постоянных 60 FPS. Отчёт artifacts/thegame/report.json сохраняет фактические значения и время стартовой подготовки отдельно.
