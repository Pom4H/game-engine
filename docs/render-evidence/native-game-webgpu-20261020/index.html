Условия и границы

  • 1280x720 output and internal render resolution; renderScale=1; adaptive quality off; TAA on, bloom/motion blur/DOF off.
  • Three repetitions per case per host, each 180 path warmup frames + 180 measured frames; static/camera case order alternates. All native runs precede browser runs; single laptop, no thermal/random-order control.
  • Camera repeats the same 180-frame 4m-wide path; geometry, materials, decoded image and Canvas2D-label RGBA assets, camera, environment and shader options are shared.
  • Both hosts disable asynchronous environment-map baking for deterministic synchronous updates. This differs from live browser gameplay, which enables the worker.
  • Each render waits for GPU completion; native then SDL-present + 60Hz timer, browser then next requestAnimationFrame. FPS and percentiles are render-loop start intervals, not externally measured display presentation or unconstrained throughput.
  • 1% low = 1000 / mean of the slowest ceil(N*0.01) frame intervals; nearest-rank p95/p99; GPU duration from timestamp queries, excludes CPU/queue/presentation.
  • Image: reset temporal history, 64 settling frames, canonical frame index 64, fixed time/camera, raw GPU presentation texture readback; RGB 8-bit code values, alpha excluded.
  • Replay image/label upload is a comparison adapter. Production native launcher still needs general image/Canvas2D adapters; this is not a complete native port of TheGame.

Загрузка до готовности рендера: браузер 10.2 с, нативный 107.1 с. Это разный способ доставки: HTTP/JS против локального exe; время не является тестом одного лишь компилятора шейдеров. Прогрев и загрузка исключены из FPS.
