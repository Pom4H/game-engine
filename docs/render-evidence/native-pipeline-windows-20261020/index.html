Что изменено

  • Расчёт карты окружения выполняется в отдельном нативном потоке; данные всех девяти mip-уровней передаются с владением буферами. Пока расчёт идёт, используется предыдущая полная карта, как в браузере.
  • Перед следующим кадром ожидается свободный слот, максимум два кадра в работе. Захват, resize и закрытие дожидаются необходимых GPU-операций.
  • Кеш границ геометрии проверяется до Object.isFrozen. Повторная проверка больших уже проверенных массивов занимала почти всё время подготовки пробы: 496.3 из 499.1 мс. После исправления повторных вызовов нет; подготовка пробы в отдельном тесте — 0.348 мс.
  • Ограничитель частоты рендера отделён от частоты физики: --render-fps 0 снимает программный предел, --fps по-прежнему задаёт фиксированный шаг симуляции.

Разброс между сериями

Native, камера стоит: 40.0 / 40.0 / 40.0 FPS. Камера движется: 40.0 / 40.0 / 40.6 FPS. Все серии включены в итог; причины разброса отдельно не изолированы.

Методика и границы

  • Three repetitions per case, 180 path warmup + 180 measured intervals each. No outliers or first repetitions discarded. Cases alternate order.
  • Current native timer cap is disabled; SDL FIFO remains active. Browser uses visible Chrome requestAnimationFrame. Both use the same two-frame completion bound and background lighting algorithm. Values describe render-loop start cadence, not physical display presentations.
  • Native runs precede browser runs; one laptop, no random-order or thermal control. Native per-repetition dispersion is retained rather than presenting only its best run.
  • Before-native data uses the original synchronous implementation and its 60 Hz cap; that cap was above its achieved FPS. The joint change includes background baking, two in-flight frames, avoiding repeated immutable-geometry integrity scans, and an independent render cap.
  • Object.isFrozen was measured on a real scene with a warmed geometry cache. Scene already reconstructs immutable ownership after JSON; no input-format change was needed. The earlier JSON-loss hypothesis was rejected.
  • Canonical image: return to the fixed pose/time, settle all lighting jobs, reset temporal history, render 64 settling frames and capture frame 64 directly from the GPU. During motion, both hosts retain the last complete lighting map while a replacement is calculated.
  • All geometry, materials, texture and label RGBA assets, output/internal resolution, shadows, TAA and postprocessing settings are preserved. No render-scale or LOD reduction is part of this patch.
