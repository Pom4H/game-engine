# Procedural material provenance

`oak.png` and `linen.png` are deterministic 512 × 512 RGB albedo tiles generated locally by `C:/Users/Roman/voice-agent/scripts/generate-office-materials.mjs` for Roman's Office. The generator uses only mathematical periodic fields, Node zlib and a PNG encoder. They contain no third-party images, image-service output or CDN dependency.

The same generated files were copied here so the historical fixture can serve `/assets/materials/*` without reading files from the Office application's workspace. The repository's MIT license applies to additions made here; no third-party asset license is required.
